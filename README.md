# Diabetes Meal Assistant v2
Vercel-ready Next.js app with 7-day meal plan, recipes, shopping list, print view and Telegram next-day ingredient automation.

Environment variables: TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID, TELEGRAM_WEBHOOK_SECRET, CRON_SECRET, APP_TIMEZONE=Asia/Dubai.

Cron is scheduled for 12:00 UTC (4 PM UAE). Nutrition values are approximate. The app does not change medication.
